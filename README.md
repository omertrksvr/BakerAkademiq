# 🥖 Baker - Profesyonel Fırın & Pastane Yönetim Sistemi

**Baker**, ASP.NET Core 6.0 mimarisi üzerine inşa edilmiş, modern web teknolojilerini RESTful API prensipleriyle birleştiren uçtan uca bir **Full-Stack** web uygulamasıdır. 

Proje, bir fırın işletmesinin tüm dijital operasyonlarını (ürün yönetimi, şef kadrosu, müşteri iletişimi vb.) merkezi bir sistem üzerinden yönetmesini sağlar.

---
### 🔹 Katmanlar

* **Baker.WebApi:** JSON veri sağlayan servis katmanı.
* **Baker.WebUI (MVC):** Kullanıcı ve admin arayüzü. API ile `IHttpClientFactory` üzerinden iletişim kurar.
* **Baker.DataAccess:** Entity Framework Core ile veritabanı işlemleri.
* **Baker.Entity:** Veritabanı tablolarını temsil eden model sınıfları.

---

## 🛠 Kullanılan Teknolojiler

### 🔧 **Backend**
* **.NET 6.0**
* **ASP.NET Core Web API**
* **Entity Framework Core (Code First)**

### 🗄 **Veritabanı**
* **Microsoft SQL Server**

### 🔄 **İletişim**
* **RESTful API (JSON)**

### 🎨 **Frontend**
* **ASP.NET Core Razor Views**
* **Bootstrap 5**
* **HTML5 / CSS3 / SCSS**
* **JavaScript / jQuery**

---

## 🚀 Temel Özellikler

### **🌐 Kullanıcı Arayüzü (Web Site)**
* **Dinamik Ürün Listeleme:** Kategorilere göre filtrelenebilir ürün kataloğu.
* **Hizmetler & Şefler:** İşletme kadrosunun ve hizmetlerin dinamik gösterimi.
* **İletişim Formu:** Kullanıcı mesajlarının doğrudan sisteme iletilmesi.

### **🔐 Yönetim Paneli (Admin Panel)**
* **Tam Kontrol (CRUD İşlemleri):** Ürün, kategori, şef, hizmet ve referans yönetimi.
* **Mesaj Takibi:** İletişim formundan gelen mesajların görüntülenmesi.
* **İlişkisel Veri Yönetimi:** Ürünlerin kategorilerle eşleştirilmesi.
